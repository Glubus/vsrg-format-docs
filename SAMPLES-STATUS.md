# Samples status

Real chart files per format of the [README index](README.md). **Committed** = files in `<format>/samples/` (not counting `SOURCES.md`). **Manifest** = entries of [`samples.manifest.json`](samples.manifest.json), downloaded by `sh tools/fetch-samples.sh` into the gitignored `samples-local/<format>/`. Origin, author, licence and purpose of every file are in the `samples/SOURCES.md` of each format; the "Getting samples" section of each format page repeats how to get more.

- Formats: **204**. With committed samples: **134**; with manifest samples: **71**; with both: 58; manifest only: 13; **no sample at all: 57**.
- Committed sample files: **838**. Manifest entries: **443** (136.0 MB).
- "synthetic" files are hand-written or tool-written for this repository (CC0), built from the format page and the public specification; they were not all opened in the original game, see each `SOURCES.md`.
