# Bemuse

Category: vsrg. Web-based BMS/bmson player; notes fall along fixed key columns (5K/7K/10K/14K, with scratch).

Bemuse (https://bemuse.ninja/, source https://github.com/bemusic/bemuse) plays BMS (`.bms/.bme/.bml`) and bmson charts in the browser. It reads the chart formats documented in [`../bms`](../bms/README.md) and adds a web-distribution layer (a keysound chunk pack and JSON catalogues) so songs stream without downloading a whole archive.

Format folders:
- [`bemuse/`](bemuse/README.md): `*.bemuse` keysound chunks + `metadata.json` index.
- [`bemuse-song-json/`](bemuse-song-json/README.md): `bemuse-song.json` (one song) and `index.json` (music server).

Related: [BMS family](../bms/README.md), [bmson](../bms/bmson/README.md).

Links: https://github.com/bemusic/bemuse, https://github.com/bemusic/song-workshop
