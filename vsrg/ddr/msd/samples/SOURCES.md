| synthetic-demo.msd | Public domain (CC0); hand-written for this corpus | StepmaniaFamily corpus (generated) | CC0 / public domain | synthetic, from this folder's README (translated spec of "MSD Ver 2.0 beta 1"): #TITLE #ARTIST #BPM #GAP and level-first `#SINGLE:level:mode:steps;`, `#DOUBLE`, `#COUPLE` (two step strings), modes BASIC/ANOTHER/MANIAC, 8th-note slots with `( )` and `[ ]` groups, keypad digits plus `A`/`B`; no holds (not in the format). Validated with the same ad-hoc slot counter as the DWI sample (whole measures) |

No real original `.msd` of the DDR'99-era simulator was found; files of that era are not archived anywhere open that could be verified. Because `#GAP` units differ between simulators, the synthetic file only demonstrates the grammar.

Notes: the seven `doremi-ddr_*.msd` files are REAL files of the old DDR-simulator `.msd` dialect, from the Wayback copy of the 2006 fan page `http://doremi.kalin.to/ddr/` (the same site that hosted the spec archived in the fiche). The hand-written `synthetic-demo.msd` follows the spec's level-first `#SINGLE:level:mode:` and does NOT count as real; the real files use `#SINGLE:<mode>:<level>:` like DWI.
