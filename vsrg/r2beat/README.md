# R2Beat

R2Beat (Neowiz / SEED9, Pmang portal, open beta 2005-08-25; Chinese edition "QQ Speed" / QQ音速 run by Tencent) is an online game combining roller-skating racing with rhythm: players dodge or hit obstacles ("障礙"/note) that follow the music. Obstacle kinds: up, down, left, right, diagonals, platform, stars and long ones (source: https://www.newton.com.tw/wiki/%E8%87%AA%E8%A3%BD%E9%9F%B3%E9%80%9F, read 2026-11-09). This corrects the earlier "4-key-style vertical lanes" guess. It is not a lane-based mania game, but stays in `vsrg/` because its charts are time-ordered obstacle lists of fixed kinds, closest to the other vsrg references.

Known through the rmstZ converter feature list (https://lrfasd.github.io/rmstZ/: chart `xml`, chart package `r2n`, audio package `pak`) and the community "自制音速" (custom R2Beat) scene.
