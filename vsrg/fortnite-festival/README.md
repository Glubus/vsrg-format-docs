# Fortnite Festival (Epic Games / Harmonix)

Fortnite Festival (2023+) is a Guitar Hero/Rock Band-style mode (Jam Tracks) with 5-lane highways for lead/bass/drums/vocals, also playable with Rock Band plastic guitars (Pro Lead/Pro Bass parts). Category **vsrg**: five fixed lanes toward a strike line. The chart is a MIDI file inside encrypted game data; community tools decrypt and read it. Format: [`mid`](mid/README.md) (stub).
