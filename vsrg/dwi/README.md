# Dance With Intensity (DWI)

Category: vsrg: DDR-style simulator; arrows scroll vertically along 4/6/8 fixed panel columns toward a receptor row.

Dance With Intensity is a Windows DDR simulator by SimWolf (started late 2000 as "Dance!", first public release DWI 1.0 on 14 December 2000, DWI 2.0 in July 2002 with Groove Radar and Nonstop CRS courses, current version listed as 2.50.00 on the author's site). It supported freeze arrows before DDRMAX shipped. It extended MSD with speed changes, pauses and freezes, so the author changed the extension to `.dwi` ([The History of DWI](http://dwi.ddruk.com/history.php)). The format spread widely (the lowest common denominator of "StepMania 3.0 era" packs) and still loads in StepMania, Etterna and OutFox.

Format folder: [`dwi/`](dwi/README.md), the `.dwi` simfile (plus its `.crs` course and `.lrc` lyrics companions).

Related: [StepMania family](../stepmania/README.md), [`.msd`](../ddr/msd/README.md) (DWI's ancestor), [pydance `.dance`](../pydance/dance/README.md) (pydance reads `.dwi` too and complains about it, see its `dwi-hall-of-shame.txt`).
