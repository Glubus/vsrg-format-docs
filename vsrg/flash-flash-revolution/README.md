# Flash Flash Revolution (FFR)

Category: vsrg: browser DDR-style game, 4 fixed arrow columns scrolling vertically.

FFR's current engine R^3 (rCubed, open source ActionScript: https://github.com/flashflashrevolution/rCubed) loads charts through `classes/chart/parse`: `ChartFFRLegacy` (SWF), `ChartStepmania`/`ChartSSC` (see [stepmania](../stepmania/README.md)), `ChartOSU`, `ChartQuaver`. The FFR simfile database converts uploaded `.sm`/`.dwi`/`.smzip`. Format folder: [`swf/`](swf/README.md).
