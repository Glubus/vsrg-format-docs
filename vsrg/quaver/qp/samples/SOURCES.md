# Samples: Quaver mapset package (`.qp`)

This is a container-only format: the repository keeps NO archive. Real archives were downloaded on 2026-11-09, their chart files extracted (media discarded) and the archives deleted. The extracted charts and their provenance (source URL of the archive, date, sha256 of the original download) are listed in `quaver/qua/samples/SOURCES.md`, in the section `Extracted from archives`: [../qua/samples/](../../qua/samples/); subfolders: `quaver-default_*/` subfolders (7 default mapsets, 4-7 `.qua` each).
