# YARG (Yet Another Rhythm Game)

YARG is an open-source (C#/Unity) plastic-instrument rhythm game by YARC. It reads Clone Hero charts (`notes.mid` / `notes.chart` + `song.ini`, see [clone-hero](../clone-hero/README.md)), `.sng` packages, Rock Band CON files and `songs.dta`, and its own `.yargsong` package (see the Packages section of the root README). YARG has no chart format of its own, so this game has no format folder. Parser code: https://github.com/YARC-Official/YARG.Core . Category: vsrg.
