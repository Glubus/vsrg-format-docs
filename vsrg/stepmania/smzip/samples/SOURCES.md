# Samples: StepMania `.smzip` (container only)

Container only: `.smzip` is a ZIP package, and the repository holds no archives. The four `.ctl` files here are the REAL `smzip.ctl` control files extracted from smpackage-built packages (CRLF text); the charts of those packages are in [`../../sm/samples`](../../sm/samples/SOURCES.md) and [`../../../dwi/dwi/samples`](../../../dwi/dwi/samples/SOURCES.md). Observed while probing real packages (not kept): StepMania AMX's `PNEXT2.smzip` and `PiuSMNX2_RDX.smzip` (theme packages, WinZip-AES encrypted, method 99); the SourceForge OldFiles `.smzip` packages (`Ez2Support9OCT2003.smzip`, `ez2__support.smzip`, `SMMAX2*.smzip`) contain themes/noteskins only.
