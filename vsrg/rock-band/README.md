# Rock Band (Harmonix)

Rock Band (2007+) and Guitar Hero 1/2 define the MIDI chart layout reused by Clone Hero/YARG ([clone-hero/mid](../clone-hero/mid/README.md)). Only the song database `songs.dta` ([dta](dta/README.md)) is documented here. Charts are Standard MIDI files inside CON/LIVE (Xbox 360) or PKG (PS3) packages, which are not documented (YARG reads extracted and non-extracted CON files and extracted PS3 PKGs with `.mid.edat`).

Category: vsrg (fixed lanes toward a strike line, as in Clone Hero).
