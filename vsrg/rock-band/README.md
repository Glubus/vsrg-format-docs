# Rock Band (Harmonix)

Rock Band (2007+) and Guitar Hero 1/2 define the MIDI chart layout reused by Clone Hero/YARG (see [clone-hero/mid](../clone-hero/mid/README.md)). The Rock Band-specific file documented separately is the song database `songs.dta` ([dta](dta/README.md)). Charts themselves are Standard MIDI files inside CON/LIVE (Xbox 360) or PKG (PS3) packages; those archive formats are not documented here (YARG supports extracted and non-extracted CON files and extracted PS3 PKGs with `.mid.edat`).

Category: vsrg (same reasoning as Clone Hero: fixed lanes toward a strike line).
