# DJMAX

DJMAX is the Pentavision/Neowiz rhythm franchise: DJMAX Online (PC, 4/5/6/8 keys, vertical falling notes), DJMAX Portable / Trilogy / Respect / Respect V (console/PC, 4-8 key vertical), DJMAX Technika (arcade, touch screen) and Technika Q / Tune (mobile). Notes on 4-8 fixed lanes: **vsrg** (Technika's touch charts are not column-based: see [others/djmax-technika-q](../../others/djmax-technika-q/bytes/README.md)).

| Folder | File | Role |
|---|---|---|
| [pt/](pt/README.md) | `.pt` ("PTFF") | pattern file of DJMAX Online and DJMAX Technika (arcade); same container family as EZ2DJ's EZFF |

DJMAX Portable, Trilogy, Respect and Respect V chart formats: no public specification found (Unknown). The original README lists only `.pt`.
