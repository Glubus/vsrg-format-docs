# Interlude (YAVSRG)

Interlude is the vertical-scrolling rhythm game client of the YAVSRG project by percyqaz ("YET ANOTHER VERTICALLY SCROLLING RHYTHM GAME", https://www.yavsrg.net). It imports osu!mania, StepMania/Etterna and Quaver libraries and keeps the charts in its own database. The game client (`interlude/`) is GPLv3; the chart/data library Prelude (`prelude/`) and the other folders are MIT (YAVSRG/YAVSRG `LICENSE`, @ a7c78e77733595749e63da26b5300e8962a4e111).

Category: **vsrg** (3-10 keys, vertical scrolling: `Chart.CheckForErrors` rejects key counts outside 3..10).
