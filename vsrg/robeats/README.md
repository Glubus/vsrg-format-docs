# RoBeats (Roblox)

RoBeats is a 4-key vertical rhythm game on Roblox by RobeatsDev (developer spotco, composer FinnMK; "a Roblox MMORPG rhythm game created by RobeatsDev" per its fandom wiki). Taps and holds fall down four tracks. In October 2020 spotco open-sourced the engine as the "RoBeats Custom Server Template" (a Roblox place and GitHub repo spotco/RobeatsCustomServerTemplate; the older "Mapping Place" dates from 2017). Its Roblox ModuleScript (Lua) per song is the only public chart format of the game.

Category: vsrg (four fixed tracks, taps and holds).

Other Roblox rhythm games (e.g. Funky Friday) have no public official chart format; third-party exploit scripts that convert osu!mania charts for Funky Friday exist but violate Roblox's terms of service and are not documented here.
