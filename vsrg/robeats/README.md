# RoBeats (Roblox)

RoBeats is a 4-key vertical-scrolling rhythm game on Roblox by RobeatsDev (developer spotco, composer FinnMK; "a Roblox MMORPG rhythm game created by RobeatsDev" per its fandom wiki). Notes (single taps and holds) fall down four tracks. In October 2020 spotco open-sourced the game engine as the "RoBeats Custom Server Template" (a copy-able Roblox place and the GitHub repo spotco/RobeatsCustomServerTemplate; the older "Mapping Place" dates from 2017 per the fandom wiki), which is the only public chart format of this game family: a Roblox ModuleScript (Lua) per song.

Category: **vsrg** (four fixed tracks, vertical scrolling, taps and holds).

The official RoBeats game's own song data (hundreds of songs) is stored in Roblox and not public; no format for it was found. Other Roblox rhythm games (e.g. Funky Friday) were looked at: no public official chart format was found; third-party exploit scripts that convert osu!mania charts for Funky Friday exist but are not documented here (they require violating Roblox's terms of service).
