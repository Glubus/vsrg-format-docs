# MUSYNX (Musync)

MUSYNX (喵赛克, "Musync"), a 4-key/6-key falling-note rhythm game by I-Inferno / Wave Game (PC 2018; mobile and "Return" versions exist), plays charts as `.txt` files (plaintext or encrypted). Category vsrg: fixed key lanes, notes falling toward a judgement line.

Format: [`txt`](txt/README.md) (stub; no public specification).
