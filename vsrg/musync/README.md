# MUSYNX (Musync)

MUSYNX (喵赛克, "Musync"), a 4-key/6-key falling-note rhythm game by I-Inferno / Wave Game (PC version 2018; a mobile and a "Return" version exist), plays charts as `.txt` files (plaintext or encrypted variants). Category **vsrg**: fixed key lanes with notes falling toward a judgement line.

Format: [`txt`](txt/README.md) (stub; no public specification).
