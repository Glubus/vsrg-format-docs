# Malody

Malody / Malody V is a cross-platform rhythm game and chart community by Mugzone (first release 2014, Key mode). It has an in-game chart editor, an online chart store (see the official Store API), skins and Lua editor plugins. Modes: Key, Catch, Pad, Taiko, Ring, Slide, Live, Cube (older versions: Step, DJ).

Category **vsrg**: Key mode, the bulk of the charts, is a fixed-column vertical scroller (4K–9K); the non-column modes are documented inside the mc page because they share the file format.

Formats:
- [`mc`](mc/README.md): JSON chart, one per difficulty and mode (ROX reads/writes Key mode only).
