# Malody

Malody / Malody V is a cross-platform rhythm game and chart community by Mugzone (first release 2014, Key mode). It has an in-game chart editor, an online chart store (official Store API), skins and Lua editor plugins. Modes: Key, Catch, Pad, Taiko, Ring, Slide, Live, Cube (older versions: Step, DJ).

Category vsrg: Key mode, most of the charts, is a fixed-column vertical scroller (4K-9K). The other modes share the file format and are documented in the mc page.

Formats:
- [`mc`](mc/README.md): JSON chart, one per difficulty and mode (ROX reads/writes Key mode only).
