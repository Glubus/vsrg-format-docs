# Samples: SOUND VOLTEX arcade chart (`.vox`)

No retail Konami chart is committed (arcade `.vox` files are extracted from game data, see the `Getting samples` section of the fiche). Committed: converter exports of synthetic KSON charts (FORMAT VERSION 13), and 11 real custom practice charts in arcade layout (FORMAT VERSION 10). All plain ASCII text, LF line endings, bytes unchanged.
