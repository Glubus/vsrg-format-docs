# Samples: SOUND VOLTEX arcade chart (`.vox`)

No real Konami chart is committed: arcade `.vox` files are extracted from game data (see the `Getting samples` section of the fiche). The files below are `.vox` **exports of synthetic KSON charts** produced by converters (FORMAT VERSION 13), plain text, ASCII, LF line endings, bytes unchanged.
