# BanG Dream! Girls Band Party (Bushiroad / Craft Egg)

Mobile rhythm game (2015+): seven lanes with notes travelling in perspective toward a judgement line at the bottom. Notes: tap, long (hold), slide (connected, with lane changes), flick, directional flick. Category vsrg: fixed lane columns and vertical approach; a column model can only approximate slides.

Formats:
- [`bestdori-json`](bestdori-json/README.md): Bestdori community chart JSON (exchanged by fan charts and Bestdori/BanGCraft tooling).
- [`txt`](txt/README.md): `beat/type/lane` text chart of BanG! Simulator (the `.txt` "BanG Dream!" chart of the original list; also written by rmstZ).
- [`bdon/`](bdon/README.md): BanG Dream! Our Notes JSON chart.

Tools: Bestdori (https://bestdori.com), BanGConverter (https://github.com/loader3229/BanGConverter, input Bestdori v1 / BanG! Simulator; output Bestdori v2, bangbangboom v1, BanG! Simulator 1/2, BanG!Craft, BMS), bangbangboom-editor (https://github.com/K024/bangbangboom-editor), BanG! Simulator (https://github.com/thtl1999/BanG-simulator), rmstZ (https://lrfasd.github.io/rmstZ/).
