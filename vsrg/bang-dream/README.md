# BanG Dream! Girls Band Party (Bushiroad / Craft Egg)

Mobile rhythm game (2015+): seven lanes with notes travelling (in perspective) toward a judgement line at the bottom; tap notes, long (hold) notes, slide (connected) notes with lane changes, flick and directional flick notes. Category **vsrg**: fixed lane columns and vertical approach; slides move between lanes, which a column model can only approximate.

Formats documented:
- [`bestdori-json`](bestdori-json/README.md): the Bestdori community chart JSON (what fan charts and Bestdori/BanGCraft tooling exchange).
- [`txt`](txt/README.md): the `beat/type/lane` text chart of BanG! Simulator (the `.txt` "BanG Dream!" chart of the original list; also written by rmstZ).

Tools: Bestdori (https://bestdori.com), BanGConverter (https://github.com/loader3229/BanGConverter, input Bestdori v1 / BanG! Simulator; output Bestdori v2, bangbangboom v1, BanG! Simulator 1/2, BanG!Craft, BMS), bangbangboom-editor (https://github.com/K024/bangbangboom-editor), BanG! Simulator (https://github.com/thtl1999/BanG-simulator), rmstZ (https://lrfasd.github.io/rmstZ/).

Added format page: [`bdon/`](bdon/README.md) (BanG Dream! Our Notes JSON chart).
