# DJ Hero

DJ Hero (Freestyle Games / Activision, 2009) is a turntable rhythm game: three tap lanes (green, blue, red), scratch zones and a crossfader on a highway scrolling toward a strike line. Custom-chart formats: the game's `.xmk` ([xmk](xmk/README.md)) and a `.chart`-based proposal in GuitarGame_ChartFormats (Proposed-Formats/DJ-Hero-Customs; page empty when consulted). Category: vsrg (lane highway), though crossfader/scratch notes do not fit plain columns.
