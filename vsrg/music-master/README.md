# Music Master (乐动达人)

乐动达人 ("Music Master", RedAtoms Studio, Chinese mobile game, 2012; successor 乐动时代 = [Music Times](../music-times/README.md)) is a vertical-scroll (osu!mania-like lanes) mobile rhythm game with community-made charts. Chart file: [xml](xml/README.md). Site: http://www.redatoms.com/games/yddr/.
