# Rocksmith 2014 (Ubisoft)

Rocksmith teaches real guitar/bass with a real-instrument cable: notes scroll toward the player along a 3D highway where lanes are the six strings and position/fret numbers show where to fret. Category **others**: a note is a (string, fret) pair with techniques (bends, slides, hammer-ons, chords with chord templates), not a plain key-count column; a ROX conversion would lose fret/technique data. Formats: [`xml`](xml/README.md) (arrangement XML written by editors) and [`sng`](sng/README.md) (the compiled binary inside `.psarc` packages). Both are stubs.

Container: [`psarc`](psarc/README.md) (the `.psarc` package wrapping `.sng`, manifests and audio; complete page, encrypted table of contents).
