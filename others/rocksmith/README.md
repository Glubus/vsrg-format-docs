# Rocksmith 2014 (Ubisoft)

Rocksmith teaches real guitar/bass through a real-instrument cable. Notes scroll toward the player on a 3D highway whose lanes are the six strings; fret numbers show where to fret. Category: others. A note is a (string, fret) pair with techniques (bends, slides, hammer-ons, chords with chord templates), not a plain key-count column; a ROX conversion would lose fret/technique data. Formats (both stubs): [`xml`](xml/README.md) (arrangement XML written by editors) and [`sng`](sng/README.md) (the compiled binary inside `.psarc` packages).
