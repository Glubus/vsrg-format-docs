# Dynamix

Dynamix (C4Cat, 2014) is a touch rhythm game with a center field plus left and right side fields. Notes fall with free x position and width; side areas are PAD (taps) or MIXER (sliding region, chained notes). Editors: Dynamaker (omegaPi), Dynamaker-modified, DyNode (NordLandeW).

Category: others (continuous x/width, three independent fields).

- [`xml/`](xml/README.md) - Dynamix chart XML (two dialects: Dynamaker `CMap` XML and the in-game `DynamixMap` XML).
- [`dy/`](dy/README.md) - `.dy` bundle (Dynamaker; chart + music + background as base64 in one file; stub).

Links: <https://github.com/jmakxd/dynamaker-modified>, <https://dyn.iorinn.moe/en/>, <https://tlchicken.github.io/dynamaker-guide/>.
