# Dynamix

Dynamix (C4Cat, 2014) is a touch rhythm game with three areas: a main center field plus left and right side fields; notes fall vertically with **free x position and width**, and side areas are either *PAD* (taps) or *MIXER* (a sliding mixer region, with chained notes). Hold notes may be long. The community editors Dynamaker (omegaPi), Dynamaker-modified and DyNode (NordLandeW) edit charts as XML or `.dy` files.

Category: **others**: continuous x/width and three independent fields; not a column-count model.

Formats documented:

- [`xml/`](xml/README.md) - Dynamix chart XML (two dialects: Dynamaker `CMap` XML and the in-game `DynamixMap` XML).
- [`dy/`](dy/README.md) - `.dy` bundle (Dynamaker; chart + music + background as base64 in one file; stub).

Links: <https://github.com/jmakxd/dynamaker-modified>, <https://dyn.iorinn.moe/en/>, <https://tlchicken.github.io/dynamaker-guide/>.
