# Love Live! School Idol Festival (SIF)

SIF (KLab / Bushiroad, 2013-2023) is a touch rhythm game with **9 circular buttons arranged on a semicircle**: notes (circles, hold notes, star notes, simultaneous notes) spawn at the centre and travel radially to a button position. Community live simulators (SIFTrain, livesim2, LLPractice) exchange beatmaps as JSON.

Category: **others**: radial travel from a centre point to 9 fixed positions of a semicircle (not parallel lanes with a vertical judgement line).

Format documented: [`sift-json/`](sift-json/README.md) (the SIFTrain beatmap JSON, partial). The game's own live JSON and livesim2's native format were not read.

Links: <https://github.com/kbz/SIFTrain>, <https://github.com/DarkEnergyProcessor/livesim2_async>, <https://github.com/DarkEnergyProcessor/LLBeatmapConvert>.
