# Love Live! School Idol Festival (SIF)

SIF (KLab / Bushiroad, 2013-2023) is a touch rhythm game with 9 circular buttons on a semicircle. Notes (circles, holds, stars, simultaneous notes) spawn at the centre and travel radially to a button. Community live simulators (SIFTrain, livesim2, LLPractice) exchange beatmaps as JSON.

Category: others (radial travel from a centre point to 9 fixed positions, no parallel lanes with a vertical judgement line).

Format documented: [`sift-json/`](sift-json/README.md) (SIFTrain beatmap JSON, partial). livesim2's native format was not read.

Links: <https://github.com/kbz/SIFTrain>, <https://github.com/DarkEnergyProcessor/livesim2_async>, <https://github.com/DarkEnergyProcessor/LLBeatmapConvert>.
