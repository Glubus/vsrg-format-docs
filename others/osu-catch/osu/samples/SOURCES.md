# Samples: osu!catch beatmap (`.osu`, `Mode: 2`)

Charts only, copied byte for byte. All files have `Mode: 2`. The hit-object lines are the same as osu!standard (circle = fruit, slider = juice stream, spinner = banana shower) [per the osu! file format wiki, see the fiche]. Standard-mode files used to test the conversion to catch are in [../../osu-standard/osu/samples/](../../../osu-standard/osu/samples/).
