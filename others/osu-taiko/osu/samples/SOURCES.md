# Samples: osu!taiko beatmap (`.osu`, `Mode: 1`)

Charts only, copied byte for byte. All files have `Mode: 1`. Circles = hits (don/kat by hitsound bits), sliders = drum rolls, spinners = swells. `beatmap-analyzer_tomorrow_perfume_*` is one song (Tomorrow Perfume, tpz Despair Remix) at six difficulties (Kantan, Futsuu, Muzukashii, Oni and two Inner Oni); `beatmap-analyzer_x_u_inner_oni.osu` is a different song.
