# Samples: osu!standard beatmap (`.osu`, `Mode: 0`)

All files are charts only: the `.osu` text files were copied byte for byte (no audio, images or videos). A missing `Mode:` line means `Mode: 0` (osu!standard) by default. Format versions covered: v3, v4, v5, v6, v7, v8, v9, v12, v13, v14 and v128 (osu!lazer test marker). Several files below sit in the Catch test folder of ppy/osu because they are standard maps used to test conversion; `Mode:` was checked in each file.
