# osu!standard (osu!)

osu!standard (mode 0, the original osu! mode) is a point-and-click game: circles, sliders and spinners appear at arbitrary positions of a 512x384 playfield, with approach circles showing the hit time.

Category: **others**: free 2D positions and curved slider paths, no lanes or scrolling columns.

Format: `.osu` with `Mode: 0` (also the default when `Mode` is absent), see [osu/](osu/README.md) and the canonical doc [vsrg/osu-mania/osu/README.md](../../vsrg/osu-mania/osu/README.md).

ROX: no (refused: `Not a mania beatmap (mode=0, expected 3)`).

Links: https://osu.ppy.sh/wiki/en/Game_mode/osu%21, https://github.com/ppy/osu/tree/master/osu.Game.Rulesets.Osu
