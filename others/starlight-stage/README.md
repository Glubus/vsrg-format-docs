# THE iDOLM@STER Cinderella Girls Starlight Stage (CGSS / Deresute)

CGSS (Bandai Namco, 2015-2024; Japanese "Deresute") is a touch rhythm game with **five positions** at the bottom; notes spawn at a point at the top-centre and travel toward their position (fan-shaped, not parallel lanes). Notes: tap, hold (long), flick (left/right), slide (connected multi-lane path); the later "grand" and "witch" modes add width, extra note kinds and tempo changes.

Category: **others**: radial/fan travel from a vanishing point to fixed positions; the 5 positions are lane-like but travel is not parallel, and grand/witch modes use variable start/finish positions and sizes.

Format documented: [`csv/`](csv/README.md) (the beatmap CSV extracted from the game's database, partial).
