# THE iDOLM@STER Cinderella Girls Starlight Stage (CGSS / Deresute)

CGSS (Bandai Namco, 2015-2024; Japanese "Deresute") is a touch rhythm game with five positions at the bottom. Notes spawn at the top-centre and fan out to their position. Note kinds: tap, hold (long), flick (left/right), slide (connected multi-lane path); the later "grand" and "witch" modes add width, extra kinds and tempo changes.

Category: others. Travel is radial from a vanishing point to 5 lane-like positions, and grand/witch modes use variable start/finish positions and sizes.

Format: [`csv/`](csv/README.md) (beatmap CSV extracted from the game database, partial).
