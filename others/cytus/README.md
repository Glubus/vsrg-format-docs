# Cytus / Cytus II (and Cytoid)

Cytus (Rayark, 2012) and Cytus II (2018) are touch rhythm games built around an **active scan line** that sweeps up and down a page; notes are circles placed anywhere along the x axis of the page and are hit when the scan line crosses them. Cytoid (community game) plays fan charts in the same two chart dialects. Rayark also made Deemo and VOEZ (see the sibling folders `deemo/` and `voez/`).

Category: **others**. Notes sit at arbitrary x positions on a page, the "judgement line" is a moving scan line, and Drag/Flick/Hold notes are chained across pages. There are no columns.

Formats documented:

- [`c1-txt/`](c1-txt/README.md) - Cytus 1 text chart (`.txt`, "Rayark v2 modified": `VERSION 2` header + `NOTE` / `LINK` lines).
- [`c2-json/`](c2-json/README.md) - Cytus II / Cytoid "C2" JSON chart.

Sources: <https://cytoid.wiki/en/reference/chart/c2-format>, <https://sites.google.com/site/cytoidcommunity/charting/chart-format>, <https://github.com/Cytoid/Cytoid/wiki/b.-Chart-formats>.
