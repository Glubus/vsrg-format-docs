# Vulnus

Mouse-aim rhythm game similar to Sound Space (notes on a small grid flying toward the player). Its map folders (`meta.json` + difficulty JSON + audio + `cover.png`) are importable into Sound Space Plus (SS+ source `Song.gd`, "vulnus" import). Only the importer's view of the format is documented here; the game's own docs were not found.

Category: **others**: free-position grid notes hit by cursor, no lanes.
