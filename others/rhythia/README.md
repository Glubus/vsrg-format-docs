# Rhythia

Rhythia (formerly Sound Space Plus), a mouse-aim rhythm game by NaN Studios (per sspm-player README: "Rhythia (formerly Sound Space) is a rhythm game by NaN Studios where notes fly toward the player and must be hit with the cursor"). The "old Rhythia" Godot 3 repository `Rhythia/sound-space-plus` is marked unmaintained.

Category: **others**: free-position notes on a 3 x 3 grid hit with a cursor, no lanes.

## Formats
Rhythia reads/writes the same `.sspm` package as Sound Space Plus. The full documentation lives in [../sound-space/sspm/README.md](../sound-space/sspm/README.md) (v1, v2) and [../sound-space/txt/README.md](../sound-space/txt/README.md) (legacy Roblox text). Newer Rhythia/"Phoenyx"/"Nova" file types are mentioned in the pysspm roadmap ("Support for Pheonix/Nova Filetype (When I get my hands on the data structure)"): format Unknown, no public spec found.
