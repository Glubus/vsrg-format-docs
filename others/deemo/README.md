# Deemo

Deemo (Rayark, 2013) is a piano-themed touch rhythm game. Notes fall vertically onto a horizontal line with **continuous** x position and width, can be chained by "slide" links, and each carries the piano sound(s) it plays. Charts are JSON text assets inside Unity bundles (one per difficulty).

Category: **others**: free x/size instead of columns (a column mapping needs quantisation) and piano keysounds on notes.

Format documented: [`json/`](json/README.md).

Links: <https://github.com/water-vapor/deemo-to-midi>, <https://github.com/Bigstool/deemo-extract>, <https://www.npmjs.com/package/sonolus-deemo-engine>.
