# Hatsune Miku: Project DIVA / Project Mirai

SEGA (Crypton characters) rhythm series: *Project DIVA* (PSP 2009–2011), arcade (2012-), PlayStation 3/Vita *f* / *F* / *F 2nd* / *X*, PS4 *Future Tone* and Switch/PC *Mega Mix(+)*; the 3DS spin-off **Project Mirai** (*Hatsune Miku and Future Stars: Project Mirai*, *Mirai 2*, *Mirai DX*) shares the DSC script engine. Targets (circle, cross, square, triangle, star; hold and rush variants) fly along curved trajectories to a position on screen and must be hit with the matching button as a marker arrives, while a 3D music video plays.

**Category: others** — notes are placed at arbitrary screen positions with trajectories and are part of a full PV script (cameras, motions), not a lane-based chart.

## Formats

| Folder | Format | Notes |
|---|---|---|
| [dsc/](dsc/README.md) | `.dsc` DivaScript binary (all games: PSP1/2, arcade, f, F2, X, Future Tone / Mega Mix, Project Mirai) | opcode tables extracted from Open PD Script Editor |

Project Mirai's chart files are also `.dsc` (3DS data is mostly `bcstm`, `dsc`, `bin` files per the GBAtemp hacking thread; a DSC editor exists on VocaloidOtaku forum posts — not opened). Community modding: DivaModArchive docs, DSC Studio, ScriptEditor / Comfy Studio.
