# Smash Drums

VR drumming game (Quest and PC VR, smashdrums.com). The player smashes approaching drum-colored objects with sticks on a drum kit; six instruments (kick, snare, cymbal, tom, hi-hat, clapfire) and per-note "strength" modes (Crystal, Neutral, Burning, used in the Arcade mode). Custom songs ("Indies") are `.indies` ZIP packages. There is no official format specification; the only public description is the documentation of the community chart editor "Smash Drums Editor" (JStillxSKS), which reads and writes them.

Category: **others**: a VR game played on a 3D drum kit with stick strokes; treated like the other VR drum games, although the highway has six fixed instrument lanes (judgement call; a 6-column projection is straightforward).
