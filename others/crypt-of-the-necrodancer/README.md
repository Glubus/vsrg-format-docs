# Crypt of the NecroDancer

Rhythm roguelike by Brace Yourself Games (2015): the player moves on the beat while exploring dungeons. With Custom Music the player replaces a zone's soundtrack with an MP3/OGG file, and the game builds a list of beat positions for it (essentia-based beat tracker, or manual tapping).

Category: others. No notes or lanes: the chart is the beat grid of a song.

## Formats
| Folder | File | Status |
|---|---|---|
| [beatmap-txt/](beatmap-txt/README.md) | `<song file name>.txt` in `data/custom_music/` | plain-text list of beat positions (seconds in current builds; milliseconds in a 2017 forum sample) |
