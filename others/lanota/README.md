# Lanota

Lanota (Noxy Games, 2016) is a touch rhythm game on a rotating 3D disc: notes appear on concentric rings (tracks) and spin around the disc; tap, hold, slide and "rotate" gestures are used and the disc/camera moves during the song. Fan tooling: **Lanotalium** (chart maker, C#/Unity, by cnSchwarzer) and **Layesta** (fan chart player for iOS/Android).

Category: **others**: radial/rotating disc layout.

Format documented: [`lanotalium/`](lanotalium/README.md) (stub; no specification could be retrieved).
