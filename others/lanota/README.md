# Lanota

Lanota (Noxy Games, 2016) is a touch rhythm game on a rotating 3D disc. Notes sit on concentric rings and spin around the disc (tap, hold, slide, rotate); the disc and camera move during the song. Fan tools: Lanotalium (chart maker, C#/Unity, cnSchwarzer) and Layesta (fan chart player for iOS/Android).

Category: others (radial/rotating disc layout).

Format documented: [`lanotalium/`](lanotalium/README.md) (stub; no specification found).
