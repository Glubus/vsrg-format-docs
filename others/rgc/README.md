# RGC (rhythm game chart interchange)

RGC is a game-agnostic JSON chart format for many rhythm games and rapid prototyping, inspired by KSON (Sound Voltex) and bmson and easy to convert to/from other formats. Category: others.

Format documented: [`rgc/`](rgc/README.md).

Links: <https://github.com/rhythm-gaming/rgc>, <https://rgc.readthedocs.io/en/latest/>, <https://github.com/R2O3/rgchart> (rgchart, a Rust/WASM library for parsing and writing charts for several games).
