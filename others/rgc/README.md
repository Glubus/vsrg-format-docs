# RGC (rhythm game chart interchange)

RGC is a game-agnostic JSON chart format designed for many rhythm games and for rapid prototyping; it is inspired by KSON (Sound Voltex) and bmson and is meant to be easy to convert to/from other formats. Not tied to a game, so category **others**.

Format documented: [`rgc/`](rgc/README.md).

Links: <https://github.com/rhythm-gaming/rgc>, <https://rgc.readthedocs.io/en/latest/>, <https://github.com/R2O3/rgchart> (rgchart, a Rust/WASM library for parsing and writing charts for several games, also surfaced in searches).
