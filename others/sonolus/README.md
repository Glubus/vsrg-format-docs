# Sonolus

Sonolus is a rhythm-game platform/app. Its games are engines (user-written scripts compiled to engine data) driven by levels (cover, BGM, optional preview and a LevelData file). Many fan recreations of mobile rhythm games (Project SEKAI, Deemo, Phigros, Cytus, Arcaea-likes...) target it. Sonolus defines no gameplay: the same LevelData container can hold lane charts, free-position charts, rotating lines, etc.

Category: others. Game-agnostic entity container (engine-defined archetypes with named numeric data); only a given engine's profile may be column-like.

Formats: [`level-data/`](level-data/README.md), LevelData (gzip JSON), the chart payload of a Sonolus level.

Links: <https://wiki.sonolus.com/>, <https://github.com/Sonolus/sonolus-wiki>, <https://github.com/NonSpicyBurrito/sonolus-wiki>.
