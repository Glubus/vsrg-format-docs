# Sonolus Collection Package (SCP) (`.scp`)
Kind: package

Doc status: stub · ROX: no · Category: others · Encoding: archive

## Overview

SCP is the Sonolus Collection Package file format used between Sonolus app versions 0.5.13 and 0.6.0: collections can be exported as `.scp` files and imported back, for backups or sharing. A static server generated by `sonolus-generate-static` can also be packaged as `.scp`. Internal layout not read; a converter app (sevenc-nanashi/scp-converter) exists to convert SCP between 0.5.13 and 0.6.0.
