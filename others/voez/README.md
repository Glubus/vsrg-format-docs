# VOEZ

VOEZ (Rayark, 2017) is a touch rhythm game. Notes (taps, holds, swipes, slides) fall along **tracks** that appear, move sideways, and change width and colour over time. A community Song Editor (AndrewFM/VoezEditor) and custom-song loader exist for the Nintendo Switch and mobile versions.

Category: others. Tracks are free-floating rectangles with their own move/scale/colour keyframes, not fixed columns.

Format documented: [`json/`](json/README.md).

Links: <https://github.com/AndrewFM/VoezEditor>, <https://gbatemp.net/threads/voez-custom-songs.509678/>.
