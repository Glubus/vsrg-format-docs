# VOEZ

VOEZ (Rayark, 2017) is a touch rhythm game where notes fall along **tracks** that appear, move sideways, change width and colour over time; notes are taps (click), holds, swipes and slides attached to a track. A community Song Editor (AndrewFM/VoezEditor) and custom-song loader exist for the Nintendo Switch and mobile versions.

Category: **others**: tracks are free-floating rectangles with their own move/scale/colour keyframes, not fixed columns.

Format documented: [`json/`](json/README.md).

Links: <https://github.com/AndrewFM/VoezEditor>, <https://gbatemp.net/threads/voez-custom-songs.509678/>.
