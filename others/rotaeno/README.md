# Rotaeno

Rotaeno (Rotaeno Team, 2022/2023) is played by physically **rotating the phone**. Notes sit on a circular dial at angles (degrees) around a centre, and the dial rotates with the song. Fan tooling knows tap, flick, slide, rotate, catch and trail notes.

Category: **others**: angular dial, no lanes.

Format documented: [`chart-text/`](chart-text/README.md) (partial, from a fan chart tool).

Links: <https://github.com/adashi521/RotaenoChartTool>, <https://github.com/zznyjidi/rotaeno-tools>.
