# Muse Dash

Muse Dash (peropero / X.D. Network, 2018) is a side-scrolling rhythm runner: notes (enemies, obstacles, notes, hearts, bosses with bullets) travel **horizontally** toward the character along **two lanes** (air and ground), hit with two buttons. Custom charts are loaded by the community mod CustomAlbums (MelonLoader) as `.mdm` packages whose chart files are BMS-flavoured text files with game-specific object ids.

Category: **others**: horizontal movement toward a character, two lanes of different note families, scene/boss events (not a vertical lane-based layout).

Formats documented:

- [`bms/`](bms/README.md) - the Muse Dash dialect of BMS used for `mapN.bms`.

Links: <https://github.com/MDMods/CustomAlbums>, <https://mdmc.moe/>.
