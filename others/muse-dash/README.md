# Muse Dash

Muse Dash (peropero / X.D. Network, 2018) is a side-scrolling rhythm runner. Notes (enemies, obstacles, notes, hearts, bosses with bullets) travel horizontally toward the character along two lanes (air and ground) and are hit with two buttons. The community mod CustomAlbums (MelonLoader) loads custom charts from `.mdm` packages whose chart files are BMS-flavoured text with game-specific object ids.

Category: others. Movement is horizontal toward a character, with two lanes of different note families and scene/boss events (no vertical lane layout).

Formats documented:

- [`bms/`](bms/README.md): the Muse Dash dialect of BMS used for `mapN.bms`.

Links: <https://github.com/MDMods/CustomAlbums>, <https://mdmc.moe/>.
