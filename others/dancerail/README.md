# DanceRail

Category: **others**: notes have continuous horizontal positions and widths (not fixed columns), with camera tilt/movement and per-note speed changes.

DanceRail (DanceRail3, SORAGAME, Android) is a touch rhythm game; charts are made with the official editor DRMaker (DR3Editor is a browser alternative; "Dancerail_Import" repackages `.drb` + `.ogg` into the APK). Format folder: [`drb/`](drb/README.md).

Links: https://github.com/swordalt/DR3Editor, https://github.com/Krydar/Dancerail_Import, https://github.com/lucarioex/DanceRail3Viewer.
