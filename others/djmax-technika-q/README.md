# DJMAX Technika Q

DJMAX Technika Q (Pentavision/Neowiz, mobile port of the DJMAX Technika touch arcade): touch-screen game, notes move along three lines with touch/drag/repeat/hold/chain notes: not a fixed column layout, so **others**. Chart file: [`.bytes`](bytes/README.md). The arcade/online `.pt` is documented under [vsrg/djmax/pt](../../vsrg/djmax/pt/README.md).
